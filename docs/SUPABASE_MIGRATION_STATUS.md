# Estado de la migración a QuickBite Core

El frontend activo consume QuickBite Core API para datos y operaciones, y Firebase Authentication para el acceso Google.

| Módulo | Estado actual |
|---|---|
| Auth | Core session + Firebase Google |
| Menú | Core API |
| Orders | Core API |
| Wallet | Core API |
| Profiles | Core API |
| Notifications | Core API |
| Favorites | Core API |
| Reviews | Core API |
| Rewards | Core API |
| Parent controls | Core API |
| Staff operations | Core API |
| Admin operations | Core API |

Los directorios históricos de infraestructura anterior se mantienen como material heredado del repositorio y no forman parte del runtime activo ni de las rutas de producción.
